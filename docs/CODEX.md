# Дальнейшая работа с Codex

Откройте ChatGPT, выберите Work in → Cloud → Select environment → Create environment. Выберите `bar4you2013-ux/Pirate-storm2`, нажмите Get started. Проверьте настройку и результаты, затем Publish. После Environment published запускайте задачи через Start a new task.

Если репозиторий не виден, разрешите доступ к нему в подключении GitHub для Codex. Открытый статус репозитория сам по себе не даёт подключению право записи.

Зависимости: `python -m pip install -r requirements.txt`.

Первая задача:

> Прочитай AGENTS.md и текущий groza_morey.py. Проверь островную экономику v0.26: добычу древесины, камня и шерсти, сбор ресурсов, стоимость строительства, торговые суда, сохранение и загрузку. Исправь найденные ошибки, сохрани текущую графику и Python/Pygame. Выполни проверку синтаксиса и проверки затронутой логики. Подготовь pull request с описанием изменений и результатов проверок.

Дальше ставьте по одной конкретной задаче: что должно происходить, при каком действии игрока и как проверить результат. Проверяйте изменения и тесты перед слиянием PR. После слияния скачайте обновлённый проект для игры на компьютере.

Официальная документация: https://learn.chatgpt.com/docs/cloud
