# Гроза морей / Pirate Storm

Игра для компьютера на Python/Pygame. Текущая основа — v0.27: корабль-призрак, рынки и иконки ресурсов. Основной файл перенесён без изменений из предоставленной версии `groza_morey_v0_27_ghost_market_icons.py`.

## Запуск на Windows

Установите Python 3.10 или новее. В терминале из папки проекта:

```powershell
py -m pip install -r requirements.txt
py groza_morey.py
```

После установки зависимостей можно запускать `run_windows.bat`.

На Linux/macOS используйте `python3` вместо `py`.

## Управление

- WASD — движение персонажа и управление судном.
- E — взаимодействие; в море причаливание, на острове добыча/сбор.
- G у берега — посещение острова.
- C на острове — захват; B — меню строительства.
- 1–6 в строительстве — дом, форт, пушка, верфь, торговое судно, рынок.
- V на захваченном острове с построенным рынком — открыть рынок; 1–6 — обмен ресурсов по курсу 5 к 1.
- N в море — переключение дня и ночи для проверки боя с кораблём-призраком.
- J — журнал, M — звук, F5 — сохранение, F9 — загрузка.

## Содержимое

- `groza_morey.py` — текущая версия v0.27: островная экономика, корабль-призрак, рынки, иконки ресурсов и сохранения. Загрузка поддерживает сохранения версий 23, 26 и 27.
- MP3 рядом с игрой — звуки из сохранённого пакета v0.8.1.
- `mobile/index.html` — отдельный мобильный браузерный прототип.
- `archive/` — все найденные оригинальные Python-версии и исходный ZIP; некоторые файлы дублируют друг друга.
- `AGENTS.md` — инструкции для дальнейшей работы Codex.
- `docs/CODEX.md` — рабочий процесс и первая задача.
- `docs/IMPORT_MANIFEST.json` — список импортированных файлов и SHA-256.

Работа продолжается над логикой и механиками в Python/Pygame. Развитие графики и перенос на Godot отложены.

Исторические результаты проверки v0.26 см. `docs/VALIDATION.md`. Для текущей версии проверяйте синтаксис командой `python -m py_compile groza_morey.py`. В облаке запуск проверяется с `SDL_VIDEODRIVER=dummy` и `SDL_AUDIODRIVER=dummy`; это не заменяет проверку графики, звука и полного игрового процесса на компьютере.
